# 티처블머신 × 마이크로비트

티처블머신 이미지 모델로 웹캠 화면을 인식하고, 인식 결과를 USB 또는 블루투스로 마이크로비트에 보내는 웹앱입니다.

## 사용 방법

1. PC용 크롬 또는 엣지에서 이 페이지를 엽니다.
2. 티처블머신 모델 링크를 붙여넣고 **모델 불러오기**를 누릅니다.
3. **카메라 켜기**를 누릅니다.
4. **USB로 연결**을 누르고 마이크로비트를 선택합니다.
5. 페이지 아래쪽의 마이크로비트 코드를 MakeCode에 붙여넣어 마이크로비트에 다운로드합니다.

## 참고

- 아이패드, 사파리, 모바일 기기는 USB·블루투스 연결을 지원하지 않습니다.
- 블루투스로 연결하려면 MakeCode에서 bluetooth 확장 프로그램을 추가하고, 프로젝트 설정에서 'No Pairing Required'를 선택해야 합니다.
